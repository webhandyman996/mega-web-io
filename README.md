# Mega 2560 網頁控制台

在網頁上點 Arduino Mega 2560 的腳位，直接控制實體板子。不用安裝軟體，Chrome 或 Edge 打開網頁就能用。

## 怎麼用

1. 用 Arduino IDE 把 `mega_io/mega_io.ino` 上傳到 Mega。
2. 關掉 Arduino IDE 的序列埠監控視窗（它會佔住 USB 埠）。
3. 用 Chrome 或 Edge 打開網頁，按「連接 Mega」，選 Mega 的 COM 埠。
4. 點板子上的腳位：
   - 數位腳點一下變 HIGH，再點一下變 LOW
   - 右邊面板可以改成 PWM（有 ~ 的腳）或輸入
   - 點 A0～A15，按「開始讀取類比值」，數值會即時顯示在腳位旁
5. 下方「對應的 Arduino 程式」會列出同樣效果的程式碼。

沒有板子時，按「沒有板子，先試看看」可以用模擬模式操作。

## 指令

網頁和 Mega 之間傳的是一行一行的文字（鮑率 115200），在序列埠監控視窗也能直接打：

| 指令 | 作用 |
|---|---|
| `D9=1` / `D9=0` | 9 號腳輸出 HIGH / LOW |
| `P9=128` | 9 號腳 PWM 輸出 0～255（2～13、44～46） |
| `I22` | 22 號腳設成輸入（內建上拉），狀態改變時回報 `D22:0` |
| `AUTO=1` / `AUTO=0` | 每 0.2 秒回報 A0～A15：`A:512,13,...` |
| `RESET` | 全部腳位回到輸入 |
| `?` | 回報版本 |

0、1 號腳是 USB 通訊用，不能控制。
