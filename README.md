# 開發板網頁控制台（Mega 2560 / ESP32）

在網頁上點開發板的腳位，直接控制實體板子。不用安裝軟體，Chrome 或 Edge 打開網頁就能用。適合當初學者的硬體驗證平台：線接好後先用網頁確認硬體會動，再開始寫程式。

- Mega 2560：https://webhandyman996.github.io/mega-web-io/
- ESP32（Ai-Thinker NodeMCU-32，38 腳）：https://webhandyman996.github.io/mega-web-io/?board=esp32

## 怎麼用

1. 用 Arduino IDE 把驗證程式上傳到板子：
   - Mega 2560：`mega_io/mega_io.ino`
   - ESP32：`esp32_io/esp32_io.ino`（開發板選 ESP32 Dev Module，程式要放在英文路徑）
2. 關掉 Arduino IDE 的序列埠監控視窗（它會佔住 USB 埠）。
3. 用 Chrome 或 Edge 打開網頁，上方選板子，按「連接」，選板子的 COM 埠。
4. 點板子上的腳位：
   - 數位腳點一下變 HIGH，再點一下變 LOW
   - 右邊面板可以改成 PWM、輸入，ESP32 的 32、33 還能改成類比
   - 類比腳按「開始讀取類比值」，數值會即時顯示在腳位旁
5. 下方「對應的 Arduino 程式」會列出同樣效果的程式碼。

沒有板子時，按「沒有板子，先試看看」可以用模擬模式操作。

## 指令

網頁和板子之間傳的是一行一行的文字（鮑率 115200），在序列埠監控視窗也能直接打：

| 指令 | 作用 |
|---|---|
| `D9=1` / `D9=0` | 9 號腳輸出 HIGH / LOW |
| `P9=128` | 9 號腳 PWM 輸出 0～255 |
| `I22` | 22 號腳設成輸入（內建上拉），狀態改變時回報 `D22:0` |
| `R32` | ESP32 的 32 號腳改成類比讀取（32、33） |
| `AUTO=1` / `AUTO=0` | 每 0.2 秒回報類比值：`A:512,13,...` |
| `RESET` | 全部腳位回到輸入 |
| `?` | 回報板子種類與版本 |

Mega 的 0、1 號腳、ESP32 的 TX0、RX0 是 USB 通訊用，不能控制。ESP32 的 34、35、36（VP）、39（VN）只能當類比輸入。
